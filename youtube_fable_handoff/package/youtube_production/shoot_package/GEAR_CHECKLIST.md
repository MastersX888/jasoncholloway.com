# Gear Checklist — Shoot Package

Use this list for every session. Check off per episode in each `EP*.md` (episode-specific props listed there).

---

## Camera

- [ ] Camera body (phone 4K acceptable if locked on tripod)
- [ ] Sturdy tripod + fluid head (or fixed mount — no handheld for A-roll)
- [ ] 24–50mm equivalent lens (phone: use main lens, not ultrawide)
- [ ] Spare batteries + charger
- [ ] Fast card (64GB+) formatted before shoot
- [ ] Phone backup camera (second angle for Chladni demo only)

---

## Lighting

- [ ] Key light: LED panel or softbox, dimmable, ~3200K
- [ ] Flags / black foam board (kill spill, deepen shadows)
- [ ] Optional: small bounce (white card) for document fill
- [ ] **No ring light** for primary setup

---

## Audio

- [ ] Lavalier or shotgun mic (rode-level minimum)
- [ ] Windscreen if any outdoor B-roll
- [ ] Headphones for monitoring
- [ ] Optional: portable recorder (dual-system: video + WAV)
- [ ] Room-tone capture (30 sec per setup)

---

## Desk / set

- [ ] Black desk mat or black cloth (3×4 ft minimum)
- [ ] Tape marks for camera, plate, and document positions
- [ ] Clamps or book weights (documents flat, no flutter)
- [ ] Glass of water (voice)

---

## Graphics (capture in-camera or add in post)

- [ ] Printed OST cards (Cinzel, black stock, gold ink or marker)
- [ ] Frequency ladder card
- [ ] `f = 111.2 Hz` footer template (for post if not printed)

---

## Episode-specific kits

### EP04 pilot (Chladni) — add before first shoot

- [ ] Metal plate (steel or brass, ~8–12 in square)
- [ ] Violin bow OR rosin'd wooden stick
- [ ] Fine sand or salt (sifted)
- [ ] Small funnel or folded paper (controlled pour)
- [ ] Optional: tone generator phone app + small speaker (frequency sweep for pattern change)
- [ ] Lens cloth (fingerprints on plate kill the shot)

### EP01 / EP03 — documents

- [ ] Printed DF page with footer
- [ ] Printed CIA cover sheet facsimile (`CIA-RDP96-00792R`) — redacted styling OK
- [ ] Gateway Process title page printout (public domain cover)

### EP02 / EP05 — geography

- [ ] County map western Missouri (paper, not screen glare)
- [ ] Five map pins (different colors optional)
- [ ] KC photos if you have them: SubTropolis, Temple Lot, Community of Christ spiral (your own or licensed)

---

## Post-production (home studio)

- [ ] DaVinci Resolve (free) or equivalent NLE
- [ ] Cinzel + EB Garamond installed (match site)
- [ ] Subtitle export (SRT) — YouTube + Instagram

---

## Do not bring (anti-slop)

- AI avatar apps
- Generic stock-footage subscriptions as crutch
- Epic documentary music packs
- Ring-light-only setup

---

## One-session minimum (EP04 pilot)

If you only shoot once this month: **EP04 only** — Chladni hook + beats 1–2 + CTA. ~90 minutes setup, ~45 minutes capture, ~30 minutes room tone and B-roll.
