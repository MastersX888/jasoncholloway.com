# Growth Ledger Weekly

**Output:** `scratch/ops_reports/GROWTH_LEDGER_YYYY-Www.md`  
**Template:** `scratch/ops_reports/GROWTH_LEDGER_TEMPLATE.md`  
**Owner persona:** Alex · Morgan puts one line on `SVP_WEEKLY` and the evening checklist.

## Never auto

Do not pay, transfer, open accounts, sign vendors, buy ads, or re-price titles. Label the file **RECOMMENDATION — not a decision**.

## Steps

1. Read latest Intake / `dashboard-state` sales if present; KDP/Ingram/Play CSVs Jason provided. If missing, write **unknown** — do not estimate.
2. Fill template sections 1–5. Catalog lock: Amazon Kindle Vol I–III only; omnibus Ingram-only.
3. Mode: Pre-gate **90% hold / 10% production / 0% paid marketing** unless Jason approved Post-gate **50/30/20**.
4. G1 watch (until Jason locks other numbers): ~8 public reviews · ≥40 units T60 · ≥$500 T60. If a gate hits, add a Diana-ready unfreeze rec — still Tier-1, not execution.
5. One checklist line only. Do not dump the full table onto the evening card.
6. Compartments: no DHSS, PSLF, or Privacy Desk data.

## Manual setup (Jason)

Sales appear only after CSV/XLSX on Terminal Intake or a file in chat. Automations do not pull KDP/Ingram by themselves.
