# Thumbnail Spec — Per Episode

**Global rules:** 1280×720 px · JPG or PNG · <2 MB · readable at phone size · **no screaming faces** · black field · gold Cinzel type · one hero object.

Verify phone for custom thumbnails before relying on these.

---

## Template layout

```
┌─────────────────────────────────────┐
│  [BLACK FIELD — 90% of frame]       │
│                                     │
│     [HERO OBJECT — center-left]     │
│                                     │
│  THREE WORDS MAX          [gold]    │
│  Series micro: Facts Behind Fiction │
│                    f = 111.2 Hz     │  ← footer, small
└─────────────────────────────────────┘
```

Font: Cinzel Bold for headline; footer in Cinzel Regular, tracked.

## Production workflow

1. Shoot still during hero take (EP04, EP05 map, EP01 DF page).
2. Import to Figma 1280×720; add type per template.
3. Export JPG; view at 25% zoom — if unreadable, fewer words.
4. A/B only after 3 episodes live (don't optimize prematurely).

---

## Deferred

- Animated thumbnails
- AI-generated backgrounds
- Face-reaction crops (unless author portrait is calm, small, and editorial — not default)
