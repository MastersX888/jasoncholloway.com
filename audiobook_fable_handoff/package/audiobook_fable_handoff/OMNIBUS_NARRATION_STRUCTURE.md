## PDF extraction known defects (fix in script)

1. **Running headers** — `MASTERS X` + page number reappear mid-chapter (e.g. pages 173–174)
2. **Standalone folios** — line with only `173` before `EPILOGUE`
3. **Hard line wraps** — every PDF line break must be merged into paragraphs
4. **Duplicate title pages** — skip after first occurrence
5. **Chapter titles** — often preceded by page number on previous line

See `KNOWN_ISSUES_AUDIOBOOK.md` for full punch list.
