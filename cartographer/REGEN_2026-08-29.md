Derived artifacts were refreshed so future audits stop re-flagging prose that has
already been corrected. Read the warning below before running any phase script.

## WARNING: `corpus_raw/omnibus_v8_fulltext.txt` is the PRE-GEO-FIX omnibus

`phase1_normalize.mjs` regenerates `corpus/MASTERS_X_BOOK*_DEMY_*.txt` from that
file. The geo fixes were never written back into it — `phase8_apply_all.mjs`
applied them **directly to the corpus book files** (`fs.writeFileSync(src, text)`
where `src` is under `corpus/`).

Proof: `corpus_raw/omnibus_v8_fulltext.txt.PRE_CANON_2026-08-29.bak` is
byte-identical (sha256 `8B191B9F2363156B...`) to
`production_staging/_sources/omnibus_v8_fulltext_PRE_GEO_FIX.txt`.

**Running phase1 against the default RAW path reverts 39 geo fixes** — 12 from
`fix_geo_prose.json` and 27 from `fix_quality_hill.json`. A trial run produced
40/26/157 differing lines across the three books, the first being Picture Cave
reverting from Warren County back to Washington County.

Use the geo-fixed omnibus as input instead:

```

```

With that input, regenerated books match the live corpus exactly except for a
3-line boundary artifact (below), and Book 3 matches byte-for-byte.

## Volume-header boundary artifact

The geo-fixed omnibus repeats each volume header twice, three lines apart:

| Marker | Lines |
|---|---|
| `VOLUME ONE` | 1 and 4 |
| `VOLUME TWO` | 4654 and 4657 |
| `VOLUME THREE` | 12117 and 12120 |

`phase1` records the **last** occurrence (`if (t === "VOLUME TWO") volIdx[2] = i`),
so each book's exclusive end bound lands past the first copy of the next volume's
header. Books 1 and 2 therefore pick up a trailing blank line plus
`VOLUME TWO` / ` The Grimoire` (and `VOLUME THREE` / ` The Kingdom`). Book 3 has
no successor and is unaffected.

Content line numbering is unaffected: the regenerated books are the live books
plus three appended lines, so every real line keeps its number.

## Script change

`phase1_normalize.mjs` and `phase2_concordance.mjs` hardcoded
`ROOT = "/workspace/cartographer"` and an absolute `/workspace/audiobook_project`
audio path, so they could not run outside the original cloud environment — which
is why these artifacts sat unrefreshed since 2026-07-28. Both now resolve `ROOT`
from the script's own location, with `CARTOGRAPHER_ROOT` still available as an
override. No behavioural change when run in the original layout.

`loadAudioSlugs()` harvests only scene-slug lines, never prose, so the audiobook
scripts still carrying the old sentences do not affect these outputs.
