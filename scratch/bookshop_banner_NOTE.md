# Bookshop list banner — display quirk

Bookshop asks for **1024×800** uploads but the **list preview crops to a wide strip** (~top 25–30% visible). Do not use full-height OG art or letterboxed layouts.

**Use:** `bookshop_list_banner.png` (native 1024×800)

- All readable text lives in the **top ~250px**
- Lower 550px is dark decorative only (safe to crop)
- Exact file dimensions: **1024 × 800**

If preview still clips, try `bookshop_list_banner_wide.png` (1024×512, 2:1 strip).
