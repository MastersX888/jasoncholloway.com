# SEVENTH CITY PRESS - LAUNCH README

## Project Overview
This repository contains the Next.js 15 source code for the official website of **Seventh City Press** and the *Masters X Trilogy* by Jason Carroll Holloway.

## Current Status: Launch Candidate
The website codebase is fully prepared for launch. All text, credentials, and book cover assets have been updated to their final production versions. The codebase utilizes modern Next.js 15 App Router architecture with responsive Vanilla CSS.

## Next Steps for Launch
1. **Deployment**: Upload this source code to a hosting provider. **Vercel** is highly recommended as it is completely free, built specifically for Next.js, and offers zero-configuration deployments straight from a GitHub repository.
2. **Domain Registration**: If you haven't already, purchase the domain name (e.g., seventhcitypress.com) and point the DNS records to your Vercel deployment.
3. **Business & Banking**:
   - Proceed with the Missouri Fictitious Name Registration for "Seventh City Press" using the Idaho virtual address (to maintain your anonymity and keep your home address off public records).
   - Once registered, open a business checking account using the DBA name and the Idaho mailing address.
   - Update your IngramSpark "Publisher Compensation" and "Account Information" sections to match this bank account and the Idaho address.
4. **Author Photos**: Once your headshots are taken over the next few weeks, simply replace the typographic placeholder on the About page.

## Package Contents
- `app/` - The core Next.js routing, pages, and global layouts.
- `components/` - Reusable UI components (Header, Footer, Newsletter, Hero).
- `lib/` - Content data arrays and configuration files.
- `public/` - Static assets, including the final fixed, high-resolution book covers.
- `package.json` & `next.config.ts` - Build scripts and framework configuration.
