## 5. Known architecture failures (why Jason wants a better design)

Claude should treat these as **design inputs**, not as shame:

1. **Personas ≠ operators.** Eleven named “department heads” are prompt roles. Four skills actually produce files. Ownership is fuzzy when Morgan is also the only chair, brief-writer, and router in one chat.
2. **Cadence is incomplete.** Charter assumes daily email/social + daily checklist. Reality: checklists exist for 2026-07-29, 07-30, 08-04 only. Weekly roll-up exists for **W32 only**. Cursor Automations for 8:00/8:15 CT not fully scheduled. Proton Bridge is a runtime SPOF.
3. **Doc sprawl.** Multiple “sources of truth” with different dates: `CANON.md` (bibliographic law), `scratch/MORGAN_OPERATING_MEMORY.md` (persona + ISBN + morning brief), `scratch/SCP_AUTOMATION_MASTER_PLAN.md` (Jul 29, partially stale), `scratch/ops_reports/SCP_BUSINESS_PLAN_REFINED.md` (**ACCEPTED** Aug 2), `FOUNDATION_STATUS.md` (Jul 17, stale vs later claims), `debt_consolidation_handoff/PLATFORM_INVENTORY.md` (Jul 16, stale on several discovery claims).
4. **Deploy / binding fragility.** Git push to GitHub does not deploy author/imprint sites. Groundswell Worker deploy via incomplete `wrangler.jsonc` **wiped STATE_KV bindings** (APIs 404) until restored 2026-08-13. Consultants/agents need a config-lock so ops UI cannot silently die.
5. **QC is real but bottlenecked.** Vivian protocol is strong (ISBN, omnibus-on-Amazon, visual clip, manifest alignment). Queue has been large (45-item QA kickoff). No PASS may be invented. Human/Vivian visual QC still required for overlays.
6. **Parallel lives.** SCP imprint, PSLF job search, DHSS day job, Privacy Desk (personal OSINT, vault **outside repo**), KC events. Committee currently mixes career + imprint + personal-privacy without hard compartments except Privacy Desk.
7. **Money/legal still Jason-only with weak radar.** Form 1583 notarized Jul 29 — mail activation wait. Affirm/Cash App have appeared on checklists. No Alex “money radar” automation.
8. **Marketing freeze vs growth need.** A8 campaigns HELD; NetGalley denied until organic gates (~≥8 public reviews and/or ≥40 units / ≥$500 trailing-60d — proposed, not locked). Social v2 35/35 published Jul 30; then hold. X token repeatedly expires.
9. **Consultant vs agent ambiguity.** Jason now asks for architecture of an oversight committee **or consultants**. Current roster has no human SLA, no retainers, no “when to hire a real publicist / accountant / IP attorney.” Design must decide that.

## 8. Design questions Claude should force the megaprompt to answer

1. **Human vs AI:** Which seats must be real consultants (CPA, IP counsel, publicist, bookkeeper) vs. AI personas vs. scheduled skills?
2. **Span of control:** 11 personas + 4 agents + Privacy + KC Events + PSLF — what gets cut, merged, or off-boarded?
3. **Single source of truth:** One operating bible vs. the current document stack; what is canonical vs. archive.
4. **Cadence that actually runs:** How evening cards get assembled if Jason’s PC / Proton Bridge / Cursor Automations are down.
5. **Dashboard vs checklist:** Terminal is Access-gated and has been wrong; checklist is trusted. How do consultants use that?
6. **QC capacity:** Vivian as a role vs. a checklist vs. a hired copy editor.
7. **Growth freeze:** Who owns the organic-groundswell resume gates and when NetGalley/ads unfreeze.
8. **Career compartment:** Is PSLF/501(c)(3) inside SVP or a separate “Jason personal office”?
9. **Failure modes:** Binding wipe, token expiry, stale snapshot, missing daily sweep — detection and fallback.
10. **Handoff language:** Exact prompt blocks for Morgan / Vivian / Alex / etc. so models don’t drift.
