### P1 — Ship next (Nina implements → Vivian → Jason approve → deploy)

#### P1-1 · Meta descriptions routinely exceed ~160 characters

**Evidence (live):** Home 203 · About 292 · Books 241 · Masters X hub 194 · Vol I 222 · Chamber 229 · imprint home 193. SERP will truncate; keyword lead may be cut.

**Fix:** Shorten `description` in each page’s `buildMetadata()` call to **~140–155 chars**, lead with the searchable claim. Optionally keep a longer `socialDescription` for OG/Twitter if needed.

**Files:** page `metadata` exports under `app/**` and `seventhcitypress/app/**` (not the helper itself).

#### P1-2 · Several money titles exceed ~60–65 characters

**Evidence:** Masters X hub 76 · Vol I 72 · Omnibus 69 · Hawkes 76 · Field Notes hub + sample essays 73–78. Brand suffix `| Jason Carroll Holloway` is correct; the *pre-suffix* string is long.

**Fix:** Tighten page `title` strings (or set `socialTitle` shorter while keeping a slightly longer browser title via `titleAbsolute` only where intentional). Prefer: `Inheritance of Frequency | Masters X Vol I` pattern over full subtitle + series + brand.

#### P1-3 · Omnibus OG image is a 3.8 MB raw hardcover PNG

**Evidence:** `og:image` → `/covers/omnibus-hardcover-v3.png` · `Content-Length: 3884447`. Volumes correctly use `/opengraph-image` routes (~fast PNG).

**Fix:** Point omnibus `buildMetadata.image` at a generated `app/books/masters-x/omnibus/opengraph-image.tsx` (mirror volume pattern) or a compressed 1200×630 static asset under `public/og/`.

**File:** `app/books/masters-x/omnibus/page.tsx`

#### P1-4 · Field Notes OG assets are ~0.9–1.0 MB each

**Evidence:** `111-hz.png` 938 KB · `ars-notoria.png` 1.0 MB · `hub.png` 891 KB · served as `image/jpeg` via `_headers` workaround (extension still `.png`).

**Fix:** Re-export at ≤200–300 KB, ideally true `.jpg` filenames + metadata path update; remove JPEG-as-PNG header hack when renamed.

**Files:** `public/og/field-notes/*` · Field Notes page metadata · `public/_headers`
